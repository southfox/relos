# 🕰️ Relós – El Despertador con Sentido del Humor

📘 This README is in Spanish. [Read it in English](README.en.md)

> La alarma que te despierta… con frases que no pediste, pero necesitabas.

**Relós** es una app despertador que mezcla sonidos, frases absurdas y un estilo teatral para asegurarse de que *no tengas un buen día... sino uno memorable*. No garantiza puntualidad, pero sí risas. O al menos una ceja levantada.

---

## 🌟 Características

- ⏰ **Alarmas con humor dudoso**: frases aleatorias que tu cerebro no procesará antes del café.
- 🎭 **Estética ridículamente teatral**: porque si vas a sufrir, que sea con elegancia.
- 📱 **Versión para iPhone**: perfecta para arruinarte la siesta con estilo.
- 📲 **Soporte para Apple Watch**: posponé la alarma desde tu muñeca, aunque no puedas posponer la vida.
- 💻 **macOS opcional**: recordatorios cómicos tipo “¿no era hora de almorzar hace 3 reuniones?”
- 👁️ **visionOS (experimental y posiblemente innecesario)**: alarmas flotantes en tu universo virtual… porque sí.
